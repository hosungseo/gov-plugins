# 제안서 해부 — 별지 제1호서식 구조와 작성법

시행규칙 제2조①: 공무원제안은 **별지 제1호서식 공무원제안서**로 제출한다.
(전자 제출 시 서명 생략 가능. 발명·고안이면 설계도·도안·사진 첨부 — 시행규칙 제2조②)

## 서식 필드 (제1쪽 — 메타데이터)

| 번호 | 필드 | 작성 요령 |
|---|---|---|
| ① | 제목 | 내용을 함축적으로 요약 |
| ② | 제출기관 | 제안 내용의 소관 중앙행정기관 (복수 걸치면 주된 소관 하나 — 영 제5조④) |
| ③ | 동일·유사제안의 다른 기관 제출 여부 | 없음/있음(기관·일시) — 허위 기재 금물 |
| ④ | 주제안자 | 성명·생년월일·기여도(%) — 기여도 최대인 1인 (영 제5조③) |
| ⑤ | 공동제안자 | 각자 성명·생년월일·기여도(%) — 합계 100 |
| ⑥ | 처리 상황 공개 여부 | 공개 / 비공개(제목·채택여부는 공개) |
| ⑦ | 처리 결과 통보방식 | SMS / 전자우편 / 우편 중 택1 + 연락처 |

## 본문 (제2쪽 — 스킬이 생성하는 핵심)

### ⑧ 현황과 문제점
서식 작성방법 원문: "공무원제안 내용과 관련된 행정 운영의 현황과 문제점을
**구체적으로** 적습니다."

- 구조: 현행 제도·업무의 사실 서술 → 문제 현상(수치·사례) → 원인 구조.
- 현행 제도가 이미 있으면 그 제도의 한계를 선점 서술 ('다'목 방어).
- 감정어·평가어 최소화. "불합리하다" 대신 "연 OO건이 OO 단계에서 반려된다".

### ⑨ 개선방안
원문: "문제점을 해결할 수 있는 **창의적인 방안을 구체적으로** 적습니다."

- 구조: 개선안 요지 한 문단 → 실시 주체와 필요 조치(법령 개정 / 시스템 개선 /
  지침·서식 변경 / 예산) → 단계별 실시방법(시범→확산 권장) → 예상 장애와 대응.
- 심사기준 '실시 가능성'과 '창의성'이 이 칸에서 결정된다. 기존 방식과의
  차별점을 명시할 것.

### ⑩ 기대효과
원문: "개선방안을 적용했을 때 예상되는 효과를 적습니다."

- 정량 우선: 예산 절감액(산출 근거 포함), 처리시간 단축, 대상 건수·인원.
- 상여금 요건(영 제19조①)을 의식: ①예산 절감에 직접적·현저한 효과 ②국고·조세
  수입 증대 ③행정 업무 개선의 획기적 효과. "직접적", "현저"를 입증할 수 있는
  단위로 서술.
- 적용 범위 확장성(타 부처·범정부)을 한 줄 언급 — 심사기준 4호 대응.

## 제출 채널 (영 제5조②)

방문 · 우편 · 팩스 · **온라인 국민참여포털** 등 인터넷. 온라인 입력칸은 평문
텍스트 기준으로 작성한다.

## 처리 흐름 (제안자가 알아야 할 시간표)

1. 접수(제6조) → **30일 이내** 채택 여부 결정·통지 (제9조①)
2. 채택 시 실시 예정 시기 함께 통지 (제9조②)
3. 불채택 시 **통지받은 날부터 15일 이내** 재심사 요청 가능 (제11조①)
4. 채택제안 → 자체우수제안 결정(제14조, 기관별 심사위원회 심의) → 행안부 추천
   → 중앙우수제안 심사·결정 (제15조, 중앙우수제안 심사위원회)
5. 보상: 시상(제16·17조), 인사상 특전(제18조 — 특별승급·특별승진, 별표1),
   상여금(제19조 — 실시 성과 측정 기반, 최대 3천만원, 별표2), 실시 성과
   측정(제24조)
