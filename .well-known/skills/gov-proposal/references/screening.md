# 자격 스크리닝 — 제2조 제외사유 실무 판정

「공무원 제안 규정」 제2조제1호는 공무원제안을 "국가공무원이 자기 또는 다른
공무원의 업무와 관련하여 소관 중앙행정기관의 장에게 제출하는 **창의적인
의견이나 고안**"으로 정의하되, 다음 7가지를 제외한다. 스크리닝은 **탈락
방지**가 목적이다 — 걸릴 것 같으면 초안 단계에서 재구성한다.

## 제외사유별 판정 기준과 회피 전략

### 가. 타인의 특허권·실용신안권·디자인권·저작권 / 직무발명 보상 확정
- 판정: 개선방안의 핵심 수단이 타인의 지식재산인가?
- 회피: 특정 상용 솔루션 도입 제안이라면 "OO사 제품 도입"이 아니라 "OO 기능을
  갖춘 시스템 도입"으로 일반화하고, 조달 절차는 실시방안에 맡긴다.

### 나. 접수 기관이 이미 채택했던 제안과 동일
- 판정 불가 — 제안자만 확인 가능. 소속 기관의 제안 처리 내역(온라인
  국민참여포털 공개분 포함)을 확인하도록 안내.
- 회피: 기채택 제안과 겹치더라도 **적용 범위·수단이 실질적으로 다르면** 별개
  제안이 될 수 있다. 차별점을 ⑨개선방안 서두에 명시.

### 다. 이미 시행 중이거나 기본 구상이 유사
- 가장 억울한 탈락 사유. 시행 중인 제도의 **사각지대·미비점**을 공략하는
  제안이라면, ⑧현황과 문제점에서 "현행 OO 제도가 있으나 ~한 한계"를 먼저
  선점 서술해 심사자가 '다'목으로 분류할 여지를 차단한다.

### 라. 일반 통념상 적용하기 어려운 것
- 판정: 예산·기술·법체계상 실현 불가능하거나 비용>>효과.
- 회피: 전면 도입이 아니라 **시범 실시 → 단계 확산**으로 실시방안을 낮춰 잡는다.

### 마. 단순한 주의환기·진정·비판·건의·불만의 표시 ★최다 탈락
- 판정: "~가 문제다, 개선해야 한다"에서 멈추면 여기에 해당한다.
- 회피(=이 스킬의 존재 이유): 반드시 **구체적 실시방안**(누가, 무엇을, 어떤
  절차로)과 **측정 가능한 기대효과**를 갖춘다. 개선방안 분량이 문제점 분량보다
  적으면 위험 신호.

### 바. 특정 개인·단체·기업의 수익사업·홍보
- 판정: 특정 사업자에게 배타적 이익이 돌아가는 구조인가?
- 회피: '가'와 동일 — 기능 요건 중심으로 일반화.

### 사. 국가 사무에 관한 사항이 아닌 것
- 판정: 순수 지방사무·민간 영역이면 국가공무원 제안 대상이 아니다.
- 회피: 국가 사무 연결점(법령·국고보조·범정부 시스템)을 찾아 소관 중앙행정기관을
  다시 잡거나, 지방공무원 제안(제29조 준용)·국민제안(「국민 제안 규정」) 경로로 안내.

## 스크리닝 출력 형식

| 제외사유 | 판정 | 근거/조치 |
|---|---|---|
| 가~사 각각 | 통과 / 위험 / 확인 필요 | 한 줄 |

'위험'이 하나라도 있으면 초안 작성 전에 재구성하고, '확인 필요'는
`⟦확인 필요: …⟧`로 본문에 표시한다.
